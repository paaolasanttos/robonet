🤖 Robonet

Plataforma Web para Gerenciamento de Torneios de Robótica Educacional

O Robonet é uma plataforma web desenvolvida como Projeto Final de Curso (PFC) do curso de Bacharelado em Sistemas de Informação da Universidade de Mogi das Cruzes (UMC).

A proposta inicial consiste no desenvolvimento de uma solução integrada para auxiliar no gerenciamento de torneios de robótica educacional, centralizando informações sobre usuários, equipes, participantes, torneios, partidas e resultados.

O sistema busca reduzir a fragmentação das informações e tornar o acompanhamento das competições mais organizado, além de incorporar mecanismos de controle de acesso, auditoria, segurança e proteção de dados pessoais.
